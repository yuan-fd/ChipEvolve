## Scope

- P18: bounded-real EDACraft capability promotion and Runtime evidence.
- P19: four paper-derived method profiles and implementation traceability.
- P20: bounded benchmark generation, calibration, uncertainty, and OOD.
- P21: user decision to Campaign, Runtime, and verified learning feedback.

## Protected boundaries

- No modification of shared ORFS/OpenROAD/PDK installations.
- No credential reads or persistence, commercial EDA execution, push, or public
  deployment.
- No expensive DPLEvolve run.
- Do not modify or commit user-owned `plan/` material.
- Predictions, imported benchmarks, and synthetic samples never become observed
  learning data.
- Runtime remains the sole process and terminal-state authority.

## Acceptance

- Fixed EDACraft source and binary hashes; honest solver capability levels.
- Four cited method profiles point to tested implementation symbols.
- Calibration/OOD and deterministic benchmark tests pass.
- User approval and Runtime submission are two separate actions; verified
  terminal evidence can be ingested as observed data.
- Database backup and non-overwriting restore pass integrity/hash checks.
- Full regression, static checks, credential scan, evidence, local commit/tag,
  and trusted-network website restart complete.
