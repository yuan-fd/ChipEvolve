End-to-end tutorial

Complete every platform workflow.

Follow the sequence once with a small design. Optional branches are marked clearly and never run automatically.

  1. 1
    Generate and review RTL from a specification

    Describe behavior and ports, review the RTL, then approve.

    Shared server model included · no user API key required
  2. 2
    Run verified RTL exploration

    RTLScout proposes edits; Verilator and Yosys verify each candidate.

    Verified offline demo needs no key
  3. 3
    Produce a 3D IC implementation

    Open Backend → 3D IC, pick a design and a 3D platform, then Generate 3D.

    No API key required
  4. 4
    Produce a baseline 2D layout

    Select the RTL, use Baseline flow, then synthesize to GDS.

    No API key required
  5. 5
    Create a stage-aware batch experiment

    Review bounded candidates, then submit only the trials you approve.

    No API key required
  6. 6
    Create an agent-guided search plan

    Agent-guided search for monitored experiments and bounded repair.

    Plan review and confirmed execution are available
  7. 7
    Inspect the pinned 3D IC workflow

    Open the TaiWei branch for 3D placement, metrics, and replay evidence.

    No API key required
  8. 8
    Review results and collect verified experience

    Compare layouts and QoR, then collect evidence into the learning store.

    Only verified execution evidence is imported.
