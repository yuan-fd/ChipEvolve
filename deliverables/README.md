# 交付物索引与归档规则

本目录保存面向平台负责人审阅的中文交付物。历史文件保留原貌；新报告只补充时间戳、证据和状态，不能覆盖或把规划误写成验收事实。

| 文件 | 属性 | 当前用途 |
|---|---|---|
| `平台功能声明-供审计.md` | 历史声明 | 审计输入；其中的能力声明须以 Runtime/测试证据复核。 |
| `下阶段开发规划.md` | 历史规划 | v1.x 方向记录；不作为 v2.0 验收依据。 |
| `v2.0_审计与升级规划_待审批.md` | v2.0 基线规划 | 架构、参考资料、问题和未完成要求的主索引。 |
| `v2.0_实施与验收报告.md` | v2.0 实施记录 | 仅记录已落地变更、命令输出与明确边界。 |

运行时记忆、实验图和候选谱系不复制为 Markdown：它们分别由 SQLite append-only store、artifact hash 和 Runtime run ID 作为权威来源。面向工程决策的长期知识位于 `project_kb/`；公开知识清单位于 `knowledge/public-corpus.lock.json`。删除任何历史材料前，应先记录来源、SHA-256、保留期和替代位置，并经负责人批准。
