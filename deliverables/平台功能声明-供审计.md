## 二、平台功能声明（当前状态）

### 核心能力
1. **2D 物理设计**（ORFS 六阶段 RTL→GDS）—— 已验证端到端
2. **3D IC**（TaiWei Pin-3D 双层）—— 已验证（3 平台，3 真实变体）
3. **自然语言生成 RTL**（Spec-to-RTL，服务器 codex 模型，人工审查）
4. **批量优化**（阶段感知参数搜索，campaign）
5. **Agent 智能调参**（OptimizerAgent 迭代 + Disruptor 换向）
6. **自演化**（知识入库 + GP/BO 建议 + 行为克隆影子 + lessons/skills）
7. **Agent 轨迹审计**（所有 LLM/agent 操作可回放）
8. **插件生态**（TaiWei / RTLScout / AgenticPD / EDACraft / DPLEvolve）
9. **免登录内部模式**（`OPENROAD_PLATFORM_NO_AUTH=1`）

### 实库数据基线（审计锚点）
- 78 次 EDA 运行（7 设计，ORFS 58 + TaiWei 20，62 成功/13 失败/3 取消）
- 61 条验证通过学习观测（全 succeeded，带 run+artifact 证据指纹）
- 7 条拒绝记录（验证门，全部失败）
- 132 优化观测（8 个 BO/GP study：4×34 + 4×6）
- 12 campaigns / 68 members
- 13 条 agent 轨迹（9 spec-to-rtl + 2 recommendation + 2 测试）
- 10 RAG 知识来源 / 5 声明 / 12 benchmark
- 测试：`python3 -m pytest -q` → 233 passed

## 三、已知缺口与诚实声明（审计时重点）

| 项 | 现状 | 备注 |
| --- | --- | --- |
| CoderAgent | 仅规划接口，未真正改 OpenROAD 源码 | 与 CERBERUS 的差距 |
| 静态归因 | 参数级（相关性），非网表级逐 cone | 对齐第一名的差距 |
| lessons/skills 库 | 机制就绪 + 单测通过，真实条目为空 | 数据积累是下一步 |
| 行为克隆 | 离线模仿，非在线学习 | 影子策略，不驱动实验 |
| RAG 知识库 | 仅用于 spec 生成与推荐理由 | 未约束 BO |
| BO/GP | 仅参数响应面 | 无网表/结构信息 |
| 跨设计迁移 | 无，按设计隔离 | 每新设计从零学 |
| AgentTrace | 仅存储展示 | 未用于学习 |
