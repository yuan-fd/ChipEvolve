# 🧊 TaiWei 3D 是怎么工作的？

> 立体芯片生产线 · 从图纸到 3D 版图的完整故事（大白话版）


## 一、TaiWei 3D 是干嘛的？

> **打个比方：**普通的 2D 芯片是**平房**（一层楼），所有零件摆在一层。TaiWei 3D 是**盖两层楼的芯片**：零件分到楼上楼下两层，两层之间用"电梯"（跨层连接）互相通信。两层楼比一层楼装得多、跑得快，但盖起来也复杂得多。

TaiWei 3D 就是这台"盖两层楼"的机器：你给它图纸（RTL），它自动把设计分成上下两层，每层各自布局布线，再用跨层网络连起来，最后交给你一张"立体版图"（3D GDS）。

**名字来源：**TaiWei（太维）是一个国产的 3D 芯片设计工具，Pin-3D 是它里面做"3D 物理设计"的引擎。本平台把它的完整流程接进来，让用户在网页上就能用。


## 二、它需要什么"原料"？（输入）

机器开工前，要准备好三样东西：

| 原料 | 大白话 | 具体是什么 |
| --- | --- | --- |
| ① 设计图纸 | 芯片要干什么的描述 | RTL 代码（.v 文件）+ 约束文件（SDC：时钟多快、哪里必须准时） |
| ② 3D 工艺库 | 楼房的"建材标准" | 三层可选：**asap7_3D**（先进）、**nangate45_3D**（老牌教学用）、**asap7_nangate45_3D**（混合）——每套都含上下两层的零件库（LEF/LIB） |
| ③ 工具链 | 盖楼的机器 | 专门为 3D 编译的 OpenROAD（改版）+ Yosys，已经装在服务器的 .tools 目录里 |

> **注意：**7 个官方设计（gcd/ibex/aes 等）的图纸机器里自带了；用户自己传的任意设计，平台会**自动生成**对应的配置（相当于自动给新图纸配好施工单）。


## 三、20 道工序 —— 中间到底干了什么

这是最核心的部分。TaiWei 3D 跑一条完整的流水线，一共 20 道工序，可以分成四个阶段：


### 阶段 A：打地基（第 1-3 道）—— 先生成一层楼的初步设计

| # | 工序 | 大白话 |
| --- | --- | --- |
| 1 | 综合（synth） | 把图纸（RTL）翻译成零件清单（门电路） |
| 2 | 2D 布局规划（floorplan） | 先按一层楼摆摆看，大概占多大地方 |
| 3 | IO 摆放 | 确定芯片"门口"（输入输出引脚）在哪 |


### 阶段 B：盖两层楼（第 4-8 道）—— 拆成上下两层

| # | 工序 | 大白话 |
| --- | --- | --- |
| 4 | 分层（TritonPart） | 把一层楼的零件**分成楼上楼下两堆**，尽量均衡 |
| 5 | 生成 3D 视图 | 按两层重新摆放，生成楼层的初始结构 |
| 6 | 3D 布局规划 + IO | 给两层楼各自定地盘、定门口 |
| 7 | 拆分跨层网络 | 哪些线要"坐电梯"上下楼，提前标出来 |
| 8 | 摆放宏单元 | 大零件（如内存块）在两层分别找位置 |


### 阶段 C：装修两层楼（第 9-15 道）—— 两层各自干活

| # | 工序 | 大白话 |
| --- | --- | --- |
| 9 | 电源网络（PDN） | 两层楼都铺好"电线"（供电） |
| 10-12 | 摆放初始化 | 小零件（标准单元）开始往两层摆 |
| 13-14 | 迭代摆放 | 楼上楼下交替调整位置，让两层都摆得下、不打架 |
| 15 | 合法化 | 检查摆放是否违反规则（间距等），修正 |


### 阶段 D：接通收尾（第 16-20 道）—— 连线和检查

| # | 工序 | 大白话 |
| --- | --- | --- |
| 16 | 时钟树（CTS） | 把"心跳信号"（时钟）送到每个零件，两层都要送到 |
| 17 | 布线（全局+详细） | 把所有零件用金属线连起来，跨层走"电梯" |
| 18 | 终检 | 检查有没有连错、有没有违反规则，出报告 |
| 19 | 热分析（可选） | 测两层楼的发热情况 |
| 20 | 出成品 | 生成最终版图文件 + 指标 + 图片 |

> **关键点：**这台机器每一道工序都**写日志、留中间文件**——以后想查"哪一步出的问题"随时能查。这就是本平台"证据优先"的体现。


## 四、它交给你什么？（输出）

机器跑完，交给你一堆"成品"，都带钢印（哈希值）：

| 输出 | 大白话 | 有什么用 |
| --- | --- | --- |
| GDS 版图 | 芯片的最终"设计图"（能拿去造） | 最核心的成品 |
| DEF/ODB | 版图的过程数据 | 给其他工具继续用 |
| 3D 视图图片 | 上下两层楼的样子（图片/SVG） | 人眼直接看 |
| 指标报告 | 面积、速度、功耗、错误数 | 判断芯片好不好 |
| 跨层网络报告 | 有多少条线"坐了电梯" | 3D 的特色指标 |
| 日志 + 工具快照 | 全程记录 + 用哪版工具 | 可复现、可追溯 |


## 五、2D 和 3D 是什么关系？—— 兄弟不是父子

**2D 和 3D 是两条平行的生产线**，同一个设计，各自独立从图纸出发：

- **2D 线**：图纸 → 一层楼的版图；
- **3D 线**：图纸 → **自己内部先做一层楼的初步设计**（阶段 A）→ 再拆成两层 → 两层版图。

3D 机器**自己会完成**阶段 A 的那几步（综合、2D 布局），不需要外面先跑一个 2D。所以：

> **怎么用：**直接跑 3D 就行！如果之前恰好跑过 2D，可以把两次结果"关联"起来做对比（2D vs 3D），但**不跑 2D 也完全不影响 3D**。想跳过 3D 内部的 2D 预步骤（复用旧结果）时，可开启 SKIP_2D_PART 开关。


## 六、它是怎么接进本平台的？（插件机制）

TaiWei 3D 是挂在平台上的一个"插件"，接法像电器的"三脚插头"——只要插脚形状对，插上就能用：

> 网页按钮 → 任务单 (TaskSpec) → 调度室 (scheduler) → 适配器 (adapter) → TaiWei 机器 (20 道工序) → 成品+证据 存档案室

具体接法（都已经是真实跑通的）：

| 环节 | 大白话 |
| --- | --- |
| 网页表单 | Backend 页的 TaiWei 面板：选工艺库、填利用率/核数/CTS 层等 |
| 任务单 | 系统把表单信息打包成标准任务单（设计 + 工艺 + 参数） |
| 适配器 | 平台侧的小程序：把任务单翻译成机器能懂的指令，跑完再收集产物 |
| 机器 | 真正去调用 .tools 里的 TaiWei 工具链跑 20 道工序 |
| 后处理 | 把结果转成图片、SVG、指标，验证 via 几何没丢，全部存档 |

> **插件的好处：**将来想加新的 EDA 工具（比如别的 3D 工具），照同样的"插头规格"写个适配器就行，不影响平台其他部分。这就是"开放式平台"。
