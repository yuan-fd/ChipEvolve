一、TaiWei 3D 是干嘛的？

打个比方：普通的 2D 芯片是平房（一层楼），所有零件摆在一层。TaiWei 3D 是盖两层楼的芯片：零件分到楼上楼下两层，两层之间用"电梯"（跨层连接）互相通信。两层楼比一层楼装得多、跑得快，但盖起来也复杂得多。

TaiWei 3D 就是这台"盖两层楼"的机器：你给它图纸（RTL），它自动把设计分成上下两层，每层各自布局布线，再用跨层网络连起来，最后交给你一张"立体版图"（3D GDS）。

名字来源：TaiWei（太维）是一个国产的 3D 芯片设计工具，Pin-3D 是它里面做"3D 物理设计"的引擎。本平台平台把它的完整流程接进来，让用户在网页上就能用。

三、20 道工序 —— 中间到底干了什么

这是最核心的部分。TaiWei 3D 跑一条完整的流水线，一共 20 道工序，可以分成四个阶段：

阶段 A：打地基（第 1-3 道）—— 先生成一层楼的初步设计

#工序大白话
1综合（synth）把图纸（RTL）翻译成零件清单（门电路）
22D 布局规划（floorplan）先按一层楼摆摆看，大概占多大地方
3IO 摆放确定芯片"门口"（输入输出引脚）在哪

阶段 B：盖两层楼（第 4-8 道）—— 拆成上下两层

#工序大白话
4分层（TritonPart）把一层楼的零件分成楼上楼下两堆，尽量均衡
5生成 3D 视图按两层重新摆放，生成楼层的初始结构
63D 布局规划 + IO给两层楼各自定地盘、定门口
7拆分跨层网络哪些线要"坐电梯"上下楼，提前标出来
8摆放宏单元大零件（如内存块）在两层分别找位置

阶段 C：装修两层楼（第 9-15 道）—— 两层各自干活

#工序大白话
9电源网络（PDN）两层楼都铺好"电线"（供电）
10-12摆放初始化小零件（标准单元）开始往两层摆
13-14迭代摆放楼上楼下交替调整位置，让两层都摆得下、不打架
15合法化检查摆放是否违反规则（间距等），修正

阶段 D：接通收尾（第 16-20 道）—— 连线和检查

#工序大白话
16时钟树（CTS）把"心跳信号"（时钟）送到每个零件，两层都要送到
17布线（全局+详细）把所有零件用金属线连起来，跨层走"电梯"
18终检检查有没有连错、有没有违反规则，出报告
19热分析（可选）测两层楼的发热情况
20出成品生成最终版图文件 + 指标 + 图片
关键点：这台机器每一道工序都写日志、留中间文件——以后想查"哪一步出的问题"随时能查。这就是本平台平台"证据优先"的体现。

五、2D 和 3D 是什么关系？—— 兄弟不是父子

这是本平台纠正过的最重要一个误解：以前平台要求"必须先跑 2D，成功了才能跑 3D"——这是错的！

真相是：2D 和 3D 是两条平行的生产线，同一个设计，各自独立从图纸出发：

  • 2D 线：图纸 → 一层楼的版图；
  • 3D 线：图纸 → 自己内部先做一层楼的初步设计（阶段 A）→ 再拆成两层 → 两层版图。

注意：3D 机器自己会做阶段 A 的那几步（综合、2D 布局），不需要外面先跑一个 2D。所以：

现在的正确做法：直接跑 3D 就行！如果之前恰好跑过 2D，可以"关联"起来做对比（2D 结果 vs 3D 结果），但不跑 2D 也完全不影响 3D。机器里有个开关 SKIP_2D_PART 甚至能跳过内部那几步（除非你想复用旧结果）。

六、它是怎么接进本平台平台的？（插件机制）

TaiWei 3D 是挂在平台上的一个"插件"，接法像电器的"三脚插头"——只要插脚形状对，插上就能用：

网页按钮→ 任务单
(TaskSpec)→ 调度室
(scheduler)→ 适配器
(adapter)→ TaiWei 机器
(20 道工序)→ 成品+证据
存档案室

具体接法（都已经是真实跑通的）：

环节大白话
网页表单Backend 页的 TaiWei 面板：选工艺库、填利用率/核数/CTS 层等
任务单系统把表单信息打包成标准任务单（设计 + 工艺 + 参数）
适配器平台侧的小程序：把任务单翻译成机器能懂的指令，跑完再收集产物
机器真正去调用 .tools 里的 TaiWei 工具链跑 20 道工序
后处理把结果转成图片、SVG、指标，验证 via 几何没丢，全部存档
插件的好处：将来想加新的 EDA 工具（比如别的 3D 工具），照同样的"插头规格"写个适配器就行，不影响平台其他部分。这就是"开放式平台"。
